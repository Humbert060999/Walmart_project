Requerimientos funcionales
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------
* El sistema deberá permitir cargar información de las tiendas, incluyendo tipo y tamaño.                                                                                
* El sistema deberá permitir cargar variables externas relacionadas con las ventas, como temperatura, precio del combustible, CPI y desempleo.                           * El sistema deberá realizar un proceso de validación de los datos, identificando valores nulos, duplicados, errores de formato y valores inconsistentes.                * El sistema deberá realizar el preprocesamiento de los datos antes de utilizarlos para entrenar el modelo.                                                              * El sistema deberá generar variables derivadas (feature engineering) a partir de los datos históricos, como mes, semana, año y características relacionadas con fechas. 
* El sistema deberá permitir entrenar un modelo de Machine Learning utilizando los datos históricos disponibles.                                                         * El sistema deberá permitir evaluar el desempeño del modelo** utilizando métricas de error apropiadas para predicción de ventas.                                          * El sistema deberá permitir seleccionar y almacenar el modelo con mejor desempeño.                                                                                      * El sistema deberá permitir ingresar información de una tienda, departamento y fecha futura para realizar una predicción.                                               * El sistema deberá generar una predicción de ventas semanales para los datos ingresados.                                                                                * El sistema deberá permitir consultar las predicciones generadas anteriormente.                                                                                         * El sistema deberá mostrar gráficos y estadísticas que permitan analizar las ventas históricas y las predicciones.                                                      * El sistema deberá permitir comparar las ventas reales frente a las ventas predichas cuando los datos reales estén disponibles.                                         * El sistema deberá generar reportes con los resultados de las predicciones y el desempeño del modelo.                                                                   

Requerimientos no funcionales
-------------------------------------------------------------------------------------------------------------------------------------------------------------------------
* El sistema deberá generar una predicción individual en un tiempo razonable, idealmente inferior a 3 segundos.                                                                     * El sistema deberá poder procesar datos correspondientes a múltiples tiendas y departamentos sin modificar la arquitectura principal.                                            * El sistema deberá estar disponible para realizar predicciones cuando el servicio se encuentre operativo.                                                                       * La interfaz deberá permitir que un usuario pueda realizar una predicción sin necesidad de conocimientos de programación.                                                           * El código deberá estar organizado en módulos independientes para facilitar modificaciones y mantenimiento.                                                                     * El entrenamiento del modelo deberá utilizar configuraciones y semillas controladas para poder reproducir los resultados.                                                     * El modelo deberá alcanzar un nivel de error aceptable definido durante la etapa de evaluación.                                                                                      * El sistema deberá proteger los datos utilizados para realizar las predicciones contra accesos no autorizados.                                                                       * El sistema deberá evitar que datos incompletos o incorrectos sean utilizados para generar predicciones.                                                                            * El sistema deberá poder ejecutarse en los entornos tecnológicos definidos para el proyecto.                                                                                    * El sistema deberá registrar información sobre los datos, versión del modelo y parámetros utilizados para generar una predicción.                                                 * El sistema deberá permitir actualizar el modelo cuando se disponga de nuevos datos históricos.
